**Release date:** 2026-09-02
**Scope:** Fix for a duplicate "CopyBasket" entry in the navigation pane's folder context menu. No other changes.

## What was broken

Right-clicking a folder in Explorer's **navigation pane** (the folder tree on the left) showed the "CopyBasket" submenu twice. The first copy was complete; in the second one "Add to basket" and "Copy path" were missing and, with an empty basket, everything except "Settings" was grayed out. The file view on the right was not affected.

Explorer's tree control (`INameSpaceTreeControl`) composes a folder node's context menu from **two** separate default context menus that both insert into the **same `HMENU`**:

1. the item menu — CopyBasket's `Directory` registration, initialized with the folder as the selection;
2. the folder's own background menu — CopyBasket's `Directory\Background` registration, initialized with `pidlFolder` only.

Each menu instantiates its own handler object, so the shell's per-menu CLSID de-duplication never kicks in, and the second instance runs in background mode (no selection → no "Add to basket"/"Copy path"). In the file view only one menu is built, which is why the duplicate never appeared there.

## The fix

The top-level "CopyBasket" popup now carries a process-unique tag in its `dwItemData` (`MenuTag()` — the DLL's module handle). `QueryContextMenu` scans the menu it is handed and adds nothing if the tag is already present (`MenuHasOurPopup`). The item instance runs first, so the complete variant is the one that stays and the background instance keeps quiet. TortoiseSVN/TortoiseGit use the same technique for the same Explorer behavior.

Verified with a test host that embeds `INameSpaceTreeControl` — the very control Explorer's navigation pane uses — selects a folder node, opens its context menu and dumps the resulting `HMENU`:

| | "CopyBasket" popups | Variant kept |
|---|---|---|
| v1.7.5 | 2 (item mode at position 6, background mode at position 19) | — |
| v1.7.6 | 1 | item mode ("Add to basket" and "Copy path" present) |
